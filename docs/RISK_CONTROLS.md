# 账号风险控制

没有任何浏览器自动化工具能够保证账号永不受限。本项目控制的是可控风险，而不是伪造“绝不封号”的承诺。

## 默认策略

- 每个平台、每个账号每天最多 2 条。
- 两次成功发布至少间隔 180 分钟。
- 同账号、同平台、同标题/正文/媒体文件名 30 天内不重复。
- 所有任务先人工审批。
- 验证码、滑块、人脸或风险验证出现后锁定账号。
- 超时不自动重试。

## 推荐上线顺序

1. 测试账号，单平台，人工点击发布。
2. 测试账号，单平台，后台自动发布，每日 1 条。
3. 正式账号，每日 1～2 条，至少观察两周。
4. 再增加第二个平台；不要同时扩大平台数、账号数和发布频率。

## 不做的事情

- 验证码绕过。
- 设备指纹伪造。
- 住宅代理池或账号 IP 轮换。
- 多账号同步群发相同内容。
- 失败后无回执盲目重发。
